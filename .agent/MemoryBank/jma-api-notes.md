## forecast APIレスポンス構造

`/bosai/forecast/data/forecast/{areaCode}.json` のレスポンスは**配列**。
2要素の配列で、インデックス0が「今週の予報」、インデックス1が「週間予報」。

```
[
  {                                  // [0] 今週の予報
    "publishingOffice": "気象台名",
    "reportDatetime": "2026-03-21T05:00:00+09:00",
    "timeSeries": [
      {                              // timeSeries[0]: 天気・風・波
        "timeDefines": ["2026-03-21T06:00:00+09:00", "2026-03-22T00:00:00+09:00", ...],
        "areas": [
          {
            "area": { "name": "東京地方", "code": "130010" },
            "weatherCodes": ["101", "201", ...],  // 天気コード（文字列）
            "weathers": ["晴れ　時々　くもり", ...],
            "winds": ["北の風　後　北東の風", ...],
            "waves": ["０．５メートル", ...]
          }
        ]
      },
      {                              // timeSeries[1]: 降水確率
        "timeDefines": [...],
        "areas": [
          {
            "area": { "name": "東京地方", "code": "130010" },
            "pops": ["10", "20", "30", "40"]  // 6時間毎の降水確率（%・文字列）
          }
        ]
      },
      {                              // timeSeries[2]: 気温（全地域にあるとは限らない）
        "timeDefines": [...],
        "areas": [
          {
            "area": { "name": "東京", "code": "44132" },
            "temps": ["15", "22"]   // [最低気温, 最高気温]（摂氏・文字列）
          }
        ]
      }
    ]
  },
  {                                  // [1] 週間予報
    "timeSeries": [
      {                              // 天気コード・降水確率
        "timeDefines": ["2026-03-23T00:00:00+09:00", ...],
        "areas": [
          {
            "area": { "name": "東京地方", "code": "130010" },
            "weatherCodes": ["101", ...],
            "pops": ["20", ...],
            "reliabilities": ["B", "C", ...]  // 信頼度（A/B/C）
          }
        ]
      },
      {                              // 最高・最低気温
        "timeDefines": [...],
        "areas": [
          {
            "area": { "name": "東京", "code": "44132" },
            "tempsMin": ["10", ...],
            "tempsMinUpper": ["12", ...],
            "tempsMinLower": ["8", ...],
            "tempsMax": ["20", ...],
            "tempsMaxUpper": ["22", ...],
            "tempsMaxLower": ["18", ...]
          }
        ]
      }
    ]
  }
]
```

## 天気コード一覧（主要なもの）

JMAの天気コードは `weatherCodes` フィールドに**文字列**で格納される。

| コード | 天気 | アイコン種別 |
|--------|------|------------|
| 100 | 晴れ | sunny |
| 101 | 晴れ 時々 くもり | sunny-cloudy |
| 102 | 晴れ 一時 雨 | sunny-rainy |
| 103 | 晴れ 時々 雨 | sunny-rainy |
| 104 | 晴れ 一時 雪 | sunny-snowy |
| 110 | 晴れ 後 くもり | sunny-cloudy |
| 111 | 晴れ 後 一時 雨 | sunny-rainy |
| 200 | くもり | cloudy |
| 201 | くもり 時々 晴れ | cloudy-sunny |
| 202 | くもり 一時 雨 | cloudy-rainy |
| 203 | くもり 時々 雨 | cloudy-rainy |
| 204 | くもり 一時 雪 | cloudy-snowy |
| 300 | 雨 | rainy |
| 301 | 雨 時々 晴れ | rainy-sunny |
| 302 | 雨 時々 止む | rainy |
| 303 | 雨 時々 雪 | rainy-snowy |
| 400 | 雪 | snowy |
| 401 | 雪 時々 晴れ | snowy-sunny |
| 402 | 雪 時々 止む | snowy |
| 413 | 大雪 | snowy |

> 完全なコード一覧は `src/renderer/lib/weatherCodeMap.ts` に実装すること。

## 既知の制約・注意事項

1. **CORS**: JMA APIはCORSヘッダーを返さない → メインプロセスでfetchすること
2. **気温データの欠如**: 一部の地域コードでは気温データが含まれないことがある → `undefined` チェックが必要
3. **エリアコードの階層**: 都道府県コードと「地方」コードは異なる（例: 東京都=`130000`、東京地方=`130010`）
4. **データ更新タイミング**: 通常1日数回更新される。更新時刻は `reportDatetime` フィールドを参照
5. **天気コードは文字列**: `weatherCodes` の値は数値ではなく文字列（`"100"` など）
6. **降水確率は文字列**: `pops` の値も文字列（`"30"` など）→ 数値変換が必要
7. **週間予報の信頼度**: `reliabilities` フィールド（A/B/C）は週間予報の精度を示す。Cは参考程度
